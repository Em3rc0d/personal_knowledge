## Main conclusion

The repository is best understood as five interacting planes:

1. **Work plane** — intake, contract, shaping, execution, proof, review, delivery.
2. **Evidence plane** — exact commands, runs, receipts, artifacts, source identities.
3. **Knowledge plane** — cases, patterns, provenance, gaps, proposal impact.
4. **Procedure plane** — small installable skills with explicit trigger boundaries.
5. **Governance plane** — maturity, distribution, evals, human promotion and deprecation.

The speed mechanism is not “one huge prompt”. It is the progressive conversion of repeated reasoning into durable state, procedures and deterministic machinery.
