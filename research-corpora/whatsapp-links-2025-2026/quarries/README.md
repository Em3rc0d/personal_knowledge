# Quarries

This corpus contains discovery sources, repositories, social posts, datasets, implementation case studies and primary references.

A quarry is **not canon**.

Promotion requires:
1. exact source/provenance;
2. evidence class;
3. scope;
4. counterexamples/contradictions;
5. freshness/version handling;
6. license/provenance check where reuse is involved;
7. test/eval when the claim is operational.
