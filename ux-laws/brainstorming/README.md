# Brainstorming

Workspace for hypotheses, relationships, questions and candidate applications derived from mined evidence.

Content here is **non-normative** until promoted through later MK gates.

## Typical artifacts

- relationship maps between laws;
- possible conflicts and trade-offs;
- product scenarios;
- candidate UX patterns;
- open research questions;
- ethical concerns;
- ideas for measurement.

Default provenance for original material here: `INFERRED`, `INSPIRED` or `GENERATED`.
