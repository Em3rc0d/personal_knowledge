# Test

Verification layer for UX-law knowledge and its downstream rules.

## Test classes

- provenance integrity;
- source-vs-inference separation;
- schema validation;
- contradiction detection;
- applicability-boundary tests;
- negative tests for known misuses;
- accessibility checks;
- UX heuristic evaluations;
- design-system conformance;
- product-flow experiments;
- empirical A/B or usability evidence when appropriate.

## Fail-closed principle

A rule is not considered certified because it sounds plausible or because a UI looks polished. Certification requires the evidence defined by the current MK gate.
