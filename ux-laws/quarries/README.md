# Quarries

Quarries are focused extraction units. Each quarry turns one source/topic into compact, traceable knowledge without pretending the extraction is already an operational UX rule.

## Quarry lifecycle

```text
source discovered
  ↓
source registered in mining-site
  ↓
quarry opened
  ↓
claims paraphrased + metadata captured
  ↓
origins / evidence / caveats mined
  ↓
relationships and conflicts linked
  ↓
reviewed
  ↓
promoted into normalized MK knowledge
```

## Required boundaries

Every quarry must distinguish:

- what the source explicitly says;
- what we directly observed;
- what we infer;
- what we propose for product/design;
- confidence and unresolved questions.
