# Design

Translates validated UX knowledge into candidate product and interface design rules.

## Responsibilities

- interaction principles;
- information hierarchy;
- progressive disclosure;
- navigation and decision architecture;
- feedback and completion states;
- accessibility-aware presentation;
- design-system implications;
- patterns and antipatterns.

## Boundary

A design rule must reference the evidence/inference that motivated it and state where it does **not** apply.

During MK0 this folder is scaffolding only. Normative design rules begin after the evidence normalization gate.
