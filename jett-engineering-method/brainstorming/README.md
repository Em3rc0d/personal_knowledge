# Brainstorming

Espacio para hipótesis, alternativas, ideas, posibles arquitecturas y preguntas abiertas sobre Jett Engineering Method.

## Boundary

Nada aquí es automáticamente canon, requirement o decisión aprobada.

> **Brainstorming is not canon.**

Una idea debe atravesar razonamiento, diseño/arquitectura cuando aplique, evidencia y review antes de promoción.

## Suitable content

- candidate gates;
- alternate phase models;
- possible tooling;
- experimental agent patterns;
- open questions;
- future extensions.
