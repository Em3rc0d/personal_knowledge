# Jett Engineering Method — Mining Site

## Provenance of MK0 foundation

JEM MK0 no proviene de un único estándar externo. Su foundation está consolidada desde práctica interna repetida en proyectos, revisiones, gates de evidencia y decisiones de producto/arquitectura.

### Source classes

| Source | Provenance | Use |
|---|---|---|
| Collaborative project history | `OBSERVED` | recurring failures, gates, review patterns and workflow lessons |
| Explicit user-ratified rules | `OBSERVED` / internal canon candidate | branch policy, evidence discipline, repository structure, Jett role |
| AI-assisted synthesis | `GENERATED` | normalization and wording of the method |
| External engineering practices when later mined | label per source | future comparison and refinement |

## Important boundary

`GENERATED` synthesis is not automatically `VERIFIED` evidence.

The method becomes internal canon only through explicit review and promotion inside this repository.

## Future mining targets

MK1+ may compare JEM against primary/authoritative material on:

- Architecture Decision Records;
- software verification and validation;
- SRE/operational readiness;
- secure software development lifecycle;
- test strategy and evidence strength;
- continuous delivery and release engineering;
- agentic software engineering review patterns.

External sources must retain URL, publisher/author, retrieval date, authority level, reason collected and any licensing constraints when relevant.
