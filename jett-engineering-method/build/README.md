# Build

BUILD produce artefactos operacionales derivados de decisiones ya suficientemente cerradas.

Ejemplos:

- code;
- schemas;
- templates;
- rulesets;
- datasets;
- scripts;
- decision matrices;
- evaluation harnesses;
- reusable components.

## Boundary

> **BUILD is not the beginning.**

Un artefacto generado no se considera correcto solo porque compila o porque un agente informa `DONE`.

Toda salida relevante debe llegar a TEST/PROVE con el nivel de evidencia apropiado.
