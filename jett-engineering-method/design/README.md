# Design

Design define cómo debería comportarse y entenderse Jett Engineering Method antes de convertirlo en estructura o automatización.

Puede incluir:

- semantics;
- phase contracts;
- human/agent interaction rules;
- status language;
- success/failure states;
- review experience;
- information hierarchy.

Design expresa intención. No implica que la implementación exista ni que la decisión esté certificada.
