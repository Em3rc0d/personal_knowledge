# Plan

Plan convierte decisiones suficientemente cerradas en ejecución verificable.

## Minimum plan contract

```text
scope
non-scope
steps
dependencies
risks
deliverables
acceptance criteria
evidence required
```

## Issue Contract

Un issue ejecutable debería declarar:

```text
Problem
Desired outcome
Scope
Non-scope
Acceptance criteria
Evidence required
Dependencies
Risks
```

No crear trabajo vago como `Improve architecture`, `Study UX` o `Add AI` sin una definición verificable de terminado.

## Solution Gate

No pasar a BUILD mientras queden decisiones fundamentales abiertas que puedan cambiar arquitectura, seguridad, datos, interfaces o claims.
