# Knowledge Foundry — Products

No product is released in MK0.

This directory is reserved for compiled educational products after the product contract is validated.

Proposed future shape:

```text
products/
└── <product-slug>/
    ├── PRODUCT_BRIEF.md
    ├── SOURCE_LICENSE_MANIFEST.md
    ├── curriculum/
    ├── lessons/
    ├── labs/
    ├── assessments/
    ├── pilots/
    └── RELEASE_RECEIPT.md
```

The shape is **not canonical yet**. MK0 G3 exists specifically to test whether these artifacts earn their maintenance cost.

Allowed states:

`IDEA → DRAFT → PILOT → VALIDATED → RELEASED → MAINTENANCE → RETIRED`

Nothing under this directory overrides the source domain canon.
