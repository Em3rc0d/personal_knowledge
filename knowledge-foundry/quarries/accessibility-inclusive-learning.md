# Quarry — Accessibility and Inclusive Learning

Source: `../mining-site/S-004-accessibility-inclusive-design.md`  
Status: **NON-CANONICAL / MK0 input**

## Candidate rules

### AX-01 Separate conformance from inclusive design

WCAG answers web-accessibility conformance questions. UDL informs broader learning-design options. Neither replaces the other.

### AX-02 Accessibility is designed before production

Captions, keyboard operation, document structure, text alternatives and motion behavior belong in the product contract, not a post-release patch list.

### AX-03 Multiple means must preserve the learning construct

Alternative representation/expression is valuable when it reduces irrelevant barriers without changing the capability being taught or assessed.

### AX-04 Alignment includes delivery technology

A technically inaccessible platform can invalidate an otherwise good learning design.

## Candidate default

For first-party web course surfaces, evaluate WCAG 2.2 AA as the default internal quality target during dogfood.

This is a generated quality target, not a claim about universal legal compliance.
