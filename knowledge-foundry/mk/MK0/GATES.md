# Knowledge Foundry — MK0 Gates

## G0 — Boundary gate

PASS when:

- Knowledge Foundry responsibility is explicit;
- source domains retain technical authority;
- `em3rc0d-foundry/` overlap is resolved;
- products cannot silently become source canon;
- source input eligibility can be decided for a bounded knowledge slice.

Current: **PASS / DRAFTED — review pending**

## G1 — Provenance, rights and license gate

PASS when every candidate product can represent:

- canonical knowledge pointers;
- external source identity;
- provenance class;
- reuse status;
- attribution requirement;
- unresolved license risk;
- rights basis for reproduced/adapted material;
- separation between product-level rights and dependency rights;
- exact source/dependency revision where the claim requires it;
- staleness/refresh triggers.

Current: **OPEN**

## G2 — Compiler gate

PASS when the minimal compiler can transform one bounded capability into:

- learner contract;
- concept graph;
- outcomes;
- lesson/lab structure;
- assessment;
- evidence pointers;
- instructional-strategy choice with applicability limits;
- source-domain eligibility decision;
- dependency/staleness record;

without copying the source domain or universalizing bounded evidence.

Current: **OPEN**

## G3 — Product contract gate

PASS when the minimum product artifact set is justified by a real dogfood candidate and unnecessary artifacts are removed.

The dogfood must explicitly test whether the product needs:

- assessment interpretation/validity metadata;
- accessibility/inclusion target;
- rights/source manifest;
- knowledge dependency manifest.

Current: **OPEN**

## G4 — Pilot evidence gate

PASS when we define:

- target learner/proxy;
- pilot protocol;
- outcome-level assessment;
- evidence capture;
- revision criteria;
- promotion threshold;
- failure/hold/kill states;
- distinction between satisfaction/completion and learning evidence;
- validity/fairness boundary for the assessment;
- minimum learner-data collection and retention boundary;
- no learner-identifiable raw data stored in this public repository.

Current: **OPEN**

## MK0 closure

Required:

```text
G0 PASS
+ G1 PASS
+ G2 PASS
+ G3 PASS
+ G4 PASS
+ no material OPEN_MK0 unknowns
= MK0 closure eligible
```

A failed gate is a valid outcome. Do not lower a gate to manufacture closure.
