# Knowledge Foundry — MK0

Name: **Mine & Frame**

State: **ACTIVE**

## Mission

Establish a defensible model for turning existing `personal_knowledge` into educational products without:

- duplicating source canon;
- laundering external sources;
- confusing technical correctness with pedagogy;
- confusing pedagogy with commercial demand;
- creating course bureaucracy before the compiler model is justified.

## Inputs

- current `personal_knowledge` governance;
- Jett Engineering Method;
- source receipts and quarries;
- first mechanism quarry from S-001 Agent Skills.

## Outputs required for closure

- stable workspace boundary;
- compiler architecture candidate;
- source/license handling rule;
- educational product lifecycle candidate;
- pilot/evaluation contract;
- first dogfood selection criteria;
- resolved/routed unknowns;
- closure receipt.

## Non-goals

- building a course platform;
- publishing a paid course;
- cloning external curricula;
- creating a marketplace;
- automating the entire pipeline;
- declaring educational certification.

## Closure rule

MK0 closes by evidence against `GATES.md`, not by file count.
