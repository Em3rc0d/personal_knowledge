personal_knowledge · Evidence, promotion & reuse

Una fuente no verificada no se promociona; la reutilización material puede producir un receipt, no automáticamente.

Desliza horizontalmente → para explorar el diagrama
Relaciones y alcance del diagrama (alternativa textual)
  1. Source pointer → Resolve + verify
  2. Resolve + verify → HOLD / BLOCKED — UNKNOWN / FAIL
  3. Resolve + verify → Mining-site — VERIFIED
  4. Mining-site → Quarries
  5. Quarries → Brainstorm → Architecture
  6. Brainstorm → Architecture → Plan → Build → Test → Prove
  7. Plan → Build → Test → Prove → MK gate / review — PROVE
  8. MK gate / review → Main / canon — PASS
  9. Main / canon → Knowledge reused
  10. Knowledge reused → Usage receipt — IF MATERIAL
  • Un pointer no es evidencia; la captura/identidad/verificación puede terminar en HOLD o BLOCKED.
  • Prove representa evidencia posterior a plan, build y test, no una certificación automática.
  • MK gate no significa PASS automático. HOLD/KILL son resultados válidos y no llevan a main.
  • El uso material posterior es condición para un knowledge-usage receipt; no se emite en toda lectura.
