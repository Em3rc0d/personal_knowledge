NINFA · Local production with human approval

Narración y evidencia se generan por rutas independientes y convergen en el render; la aprobación precede la distribución.

Desliza horizontalmente → para explorar el diagrama
Relaciones y alcance del diagrama (alternativa textual)
  1. Research + script → Fact-check
  2. Fact-check → Scene manifest
  3. Scene manifest → Narration — VOICE
  4. Scene manifest → Evidence + graphics — VISUAL EVIDENCE
  5. Narration → FFmpeg + SRT
  6. Evidence + graphics → FFmpeg + SRT
  7. FFmpeg + SRT → Human approval — REVIEW
  8. Human approval → YouTube — APPROVED
  9. YouTube → Analytics / learn
  10. Analytics / learn → Research + script — NEXT CYCLE
  • Las entradas de narración y evidencia no son una cadena obligatoria entre sí.
  • La ruta humana de aprobación es un gate previo a distribución; un render correcto no implica publicación.
  • El resultado de analytics retroalimenta investigación del siguiente episodio.
  • Este overview omite packaging, backlog, storage y derivados: ver operating model.
