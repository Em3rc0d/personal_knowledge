# Web Design — Brainstorming

Open hypotheses and future directions. Nothing here is automatically accepted architecture.

## Current questions

- What is the minimum semantic schema for a useful `DESIGN.md`-like contract?
- Should Markdown remain canonical or should a typed intermediate representation become canonical later?
- How should visual evidence reference screenshots without storing copyrighted material unnecessarily?
- How should confidence be calibrated across direct extraction, computer vision and human inference?
- How should brand/reference retrieval avoid stylistic cloning?
- What belongs in static design rules vs component state machines?
- How should UX Laws be consumed without duplicating the `ux-laws` domain?
- Which responsive transformations can be validated automatically?
- Which accessibility properties belong in design contracts vs implementation tests?
- How should design releases map to product releases?
