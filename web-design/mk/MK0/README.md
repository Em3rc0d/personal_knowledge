# Web Design — MK0: Mine & Frame

Status: `IN PROGRESS`

## Objective

Create the trustworthy research foundation for a reusable web-design knowledge system before operational schemas or automation are treated as stable.

## Seed

RICOUI is the first major mined design-system workflow because it provides concrete evidence around `DESIGN.md`, generated artifacts, brand references and human-reviewed AI editing.

RICOUI is **not** sufficient to close MK0 alone.

## Deliverables

- domain README and scope;
- source registry;
- RICOUI mining dossier;
- source-specific quarry;
- provenance vocabulary;
- source-vs-inference boundary;
- semantic design-system contract draft;
- architecture draft;
- candidate-rule inventory;
- MK0 status gate.

## Non-goals

MK0 does not certify:

- a final `DESIGN.md` schema;
- a production token generator;
- a component library;
- automated visual extraction;
- automated visual regression;
- official accuracy of third-party brand references.

## Closure rule

MK0 closes only when `../STATUS.md` acceptance criteria are all satisfied and review finds no material unlabelled source/inference mixing.
