# Web Design — Plan

## MK0 execution order

1. Register seed sources and attribution boundaries.
2. Mine RICOUI's canonical-source, artifact and brand-reference models.
3. Separate official RICOUI claims from our inferences.
4. Draft the semantic design-system contract.
5. Draft the design-knowledge architecture.
6. Add independent sources for accessibility, tokens, responsive design and component architecture.
7. Normalize evidence and provenance schemas.
8. Review licensing/copyright boundaries.
9. Run MK0 contradiction/provenance review.
10. Close MK0 only when all acceptance criteria pass.

- visual grammar;

- component contracts;
- states;
- responsive transformations;
- accessibility constraints;
- motion;
