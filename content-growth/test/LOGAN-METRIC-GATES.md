# Logan Metric & Editorial Gates

Status: `GENERATED / MK0 test contract`

These gates prevent narrative-driven decisions from replacing evidence.

## GATE-01 — Provenance

Every important claim must be tagged as one of:

- `OBSERVED`
- `INFERRED`
- `GENERATED`
- `OFFICIAL`
- `INSPIRED`

Pass condition: no inferred strategy is presented as raw platform fact.

---

## GATE-02 — Objective before metric

Every evaluated post must have a primary objective when possible:

- reach;
- comments;
- saves;
- shares;
- profile visits;
- follows;
- search discovery;
- later conversion.

Pass condition: the post is not judged only by total views when its intended job was different.

---

## GATE-03 — No-repeat

Before producing a post, compare it against recent content by:

- topic;
- symptom;
- diagnosis;
- hook mechanism;
- visual structure;
- CTA.

Pass condition: either the concept is materially new or the repetition is explicitly labeled as a controlled variation / continuation / correction.

---

## GATE-04 — Hook integrity

Pass only if:

1. the hook creates clear attention tension;
2. the body resolves that tension;
3. the claim is mechanically defensible;
4. uncertainty is preserved when diagnosis is non-unique.

Fail examples:

- catastrophic certainty from one common symptom;
- hook promises scanner-level diagnosis but body gives generic advice;
- unrelated shock phrase pasted over ordinary content.

---

## GATE-05 — Visual quality

Pass only if:

- first-frame hierarchy works at phone size;
- one dominant idea exists per slide;
- text is readable without zoom;
- imagery clarifies the mechanism or emotion;
- visual composition does not look like an unfinished template;
- the asset is export-ready as a separate post/slide when required.

---

## GATE-06 — Measurement completeness

At each window (`T+2h`, `T+24h`, `T+7d`), record what exists and leave unavailable values as `UNKNOWN`.

Pass condition: no invented attribution for profile visits, follows or conversions.

---

## GATE-07 — Promotion

A content mechanism may be promoted to a reusable pattern only after repeated evidence.

Current provisional rule:

```text
GREEN candidate
= beats rolling median in >=2 objective-relevant metrics
```

Promotion requires more than one isolated success if the claim is meant to become general.

---

## GATE-08 — Kill discipline

After three materially distinct attempts fail against the same intended objective, default action is to archive the angle.

Exception: keep testing only if there is a documented strategic reason, new evidence or a materially different hypothesis.

Pass condition: failed ideas do not return silently because topic generation became difficult.

---

## GATE-09 — Cadence safety

Four posts/day is permitted only when all of the following remain true:

```text
visual_quality = PASS
novelty = PASS
technical_integrity = PASS
measurement = SUSTAINABLE
```

Otherwise cadence must yield to quality.

---

## GATE-10 — Weekly falsification

Weekly review must ask at least:

- Which current belief lost support?
- Which “winner” failed to repeat?
- Which format looks strong only because of one topic?
- Which topic looked weak only because of packaging?
- Did profile/follow conversion improve or merely views?

Pass condition: the review contains at least one attempt to disconfirm the current strategy, not only celebrate winners.
