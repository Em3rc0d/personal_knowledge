# MK0 — Mine & Frame

## Objective

Capture the 2026-09-11 LinkedIn growth event as a reproducible knowledge package and turn it into falsifiable operating hypotheses.

## Scope

- platform metrics;
- topic performance;
- audience composition;
- funnel diagnosis;
- editorial-role model;
- profile conversion;
- CTA strategy;
- opportunity measurement;
- current four-slot daily operating model;
- anti-patterns and unknowns.

## Out of scope

- claiming universal LinkedIn algorithm rules;
- assuming causality from correlation;
- certifying the four-post cadence from one week;
- treating vanity engagement as the business objective;
- treating current topic winners as permanent winners.

## Package

- [`EVIDENCE.md`](./EVIDENCE.md)
- [`INVARIANTS.md`](./INVARIANTS.md)
- [`UNKNOWNS.md`](./UNKNOWNS.md)

## Promotion rule

A candidate rule can move toward MK1/MK2 only when it has:

1. explicit evidence source;
2. repeatability across multiple observation windows or experiments;
3. a defined metric;
4. a known failure mode / boundary;
5. no contradiction with the broader professional objective.
