# Measurement Model

## Why

The system should optimize professional value, not raw engagement.

## Funnel metrics

### Acquisition

- impressions;
- unique reach;
- outside-network reach;
- content-family reach concentration.

### Utility / resonance

- reactions;
- saves;
- saves / interactions;
- saves / impressions.

### Conversation / redistribution

- comments;
- comments / impressions;
- shares;
- shares / impressions;
- qualitative comment quality.

### Profile conversion

- profile views;
- reach → profile CTR;
- impressions → profile CTR;
- follower growth;
- profile → follow rate when observable.

### Discovery channel

- search appearances;
- feed-led vs search-led growth;
- location/role/industry audience shifts.

### Economic / professional outcome

Primary:

```text
Opportunities Generated
```

Recommended opportunity ledger fields:

| Field | Purpose |
|---|---|
| date | time series |
| opportunity_type | recruiter / interview / referral / client / contract / collaboration |
| source_post | direct attribution if known |
| source_family | SQL / authority / proof / automation / other |
| first_touch | earliest known touch |
| last_touch | latest known touch |
| profile_visit_known | yes/no/unknown |
| outcome | open / won / lost / no-fit |
| estimated_value | optional |
| notes | qualitative context |

## Experiment discipline

Change one meaningful dimension where feasible:

- topic family;
- hook class;
- visual format;
- CTA type;
- post role;
- time slot.

Avoid declaring victory from one post.

## Review windows

Suggested analysis:

- daily: anomaly / execution check;
- 7-day rolling: content performance;
- 28-day rolling: audience and funnel behavior;
- monthly: opportunity/economic review.

## Decision rules

Candidate rules should strengthen only when:

1. the effect repeats;
2. the metric is defined;
3. the comparison window is comparable;
4. alternative explanations are recorded;
5. opportunity quality is not sacrificed for vanity reach.

A post with lower reach can be more valuable if it creates a high-quality professional opportunity.
