# LinkedIn Professional Growth

Dominio de conocimiento para convertir LinkedIn en un sistema de adquisición de oportunidades profesionales mediante contenido técnico, evidencia de trabajo y optimización de funnel.

## North Star

> Que cada semana más personas con capacidad de contratar, pagar, recomendar o incluir al autor en proyectos sepan quién es y tengan evidencia de que sabe construir.

Modelo operativo:

```text
Alcance
  ↓
Credibilidad
  ↓
Evidencia
  ↓
Perfil
  ↓
Conversación
  ↓
Oportunidad
  ↓
Dinero / contrato / empleo / referral / colaboración
```

## Identidad editorial

> **Explico software de forma sencilla, pero construyo sistemas de verdad.**

La estrategia no busca una audiencia homogénea. Busca una red de distribución alrededor de capacidad profesional demostrable.

## Estado epistemológico

- `OBSERVED`: métricas y hechos visibles en LinkedIn Analytics.
- `INFERRED`: interpretación derivada de esas métricas.
- `GENERATED`: estrategia, reglas y experimentos propuestos a partir de la evidencia.
- Nada de este dominio convierte una inferencia en hecho sin etiquetarla.
- La estrategia actual es un **baseline operacional candidato**; requiere validación longitudinal.

## Audiencias objetivo

| Audiencia | Valor potencial | Evidencia que necesita |
|---|---|---|
| Recruiters / HR | entrevistas y empleo | stack, claridad, proyectos, empleabilidad |
| Tech Leads / Engineering Managers | contratación, referrals, proyectos | criterio técnico y profundidad |
| Founders / empresarios | clientes y contratos | capacidad de resolver problemas |
| Developers / profesionales | referrals, networking, colaboración | conocimiento útil + respeto técnico |
| Estudiantes / juniors | alcance e interacción | contenido accesible, útil y educativo |

Los estudiantes y juniors son parte deliberada del sistema de distribución: pueden no generar ingreso directo hoy, pero amplifican contenido que puede alcanzar a personas con capacidad de contratar o pagar.

## Tesis actual

1. SQL encontró un fuerte content–audience fit para adquisición.
2. SQL debe operar como **reach engine**, no como identidad completa.
3. La autoridad profesional se construye con backend, system design, AI/automation, DevOps, cloud y sistemas.
4. `Proof of Work` debe convertir percepción de “sabe explicar” en “sabe construir”.
5. Los posts pueden funcionar como landing page; el perfil es la segunda etapa del funnel.
6. El éxito se mide por oportunidades generadas, no solo por likes.
