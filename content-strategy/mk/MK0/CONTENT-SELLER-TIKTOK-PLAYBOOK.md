# MK0 Playbook — Content Seller / TikTok

Status: `WORKING CANON WITHIN MK0`  
Date: `2026-09-11`

This playbook promotes the current operating model from raw quarry material. It remains falsifiable and must evolve with evidence.

## 1. Objective

Build a heavy TikTok account **before Prompt Machine launch** by earning attention and trust from people who can later benefit from structured AI workflows.

The immediate target is not product sales. It is:

```text
reach
→ recognition
→ trust
→ repeat consumption
→ follower growth
→ future product fit
```

## 2. Who the account is for

Primary:

- Systems / Software / Computing / IT students;
- juniors and early-career technical profiles;
- people building university or portfolio projects;
- people learning how theory maps to real systems;
- people who want to use AI better without outsourcing their thinking.

Secondary reach may include broader developer and tech audiences, but content should remain understandable enough for the primary nucleus.

## 3. Brand promise

> **Technology explained for people who are learning to build real things.**

Secondary belief:

> **AI should improve your process, not replace your judgment.**

## 4. Daily batch composition

Default batch size: `4` as a current experiment.

```text
SLOT 1 — STUDENT REACH
Goal: broad identification, emotion, discovery.

SLOT 2 — TECH KNOWLEDGE
Goal: teach something concrete and defensible.

SLOT 3 — REAL WORLD BRIDGE
Goal: connect university theory to systems, projects, career or industry.

SLOT 4 — AI LEVERAGE
Goal: teach better AI/workflow usage and gradually prepare Prompt Machine positioning.
```

A batch fails diversity if multiple slots collapse into the same job.

## 5. Candidate generation

For four final posts:

```text
generate 8–12 candidates
→ novelty filter
→ role fit
→ diversity
→ evidence / safety
→ visual potential
→ choose 4
```

Do not trust the first four outputs.

## 6. Content allocation

Starting hypothesis:

```text
50% technical concepts
20% university / student life
20% projects / career / real-world engineering
10% AI / workflows
```

This mix is adjustable through observed performance and product timing.

## 7. Hook system

Preferred hooks create at least one of:

```text
identity
contradiction
consequence
curiosity
stakes
misconception
recognizable pain
```

Examples of useful shapes:

- “Si estudias Sistemas y esto todavía te confunde...”
- “Tu código puede estar correcto y tu sistema seguir roto.”
- “Esta materia parece inútil hasta que construyes backend.”
- “Tu app funciona en una máquina. Ahora ponla en tres.”
- “Yo no empezaría este proyecto pidiéndole a ChatGPT que lo haga.”

Avoid generic shock templates with no substantive payoff.

## 8. No-repeat gate

Check all candidates against recent history on:

```text
topic
angle
lesson
hook pattern
format
visual structure
meme premise
```

Reject semantic duplicates even when wording changes.

Default behavior:

- avoid recent topic reuse for several days and preferably ~1 week where possible;
- never repeat the same angle/hook/creative structure merely to fill a slot;
- continuation/Part 2 only when explicitly intentional.

## 9. Topic engine

Use the academic curriculum as a durable map:

```text
Programming Core
Systems / Backend
Data
AI
Software Engineering
Security
Student / University
```

Transform subject → real problem.

```text
course title
→ misconception / failure / consequence / project / industry bridge
→ hook
→ explanation
→ payoff
```

## 10. Visual system

Default canvas: `9:16`.

Quality bar:

- strong visual hierarchy;
- hooks large enough to stop scroll;
- diagrams/illustrations when they explain better than copy;
- premium editorial composition;
- recognizable Content Seller identity;
- composition diversity across the batch;
- readable safe zones for TikTok UI;
- do not produce “text pasted on background” unless the concept specifically benefits from minimalism.

A carousel must be delivered as separate usable slides; a single contact sheet is not a publishable carousel.

## 11. Caption / metadata

Current convention:

```text
#fyp #foryou ...topic-specific hashtags
```

Caption should:

- add context or deepen the post;
- avoid duplicating every word already present on-screen;
- use a CTA appropriate to the job of the post;
- favor easy, specific questions when conversation is the goal.

## 12. Prompt Machine bridge

Do not market Prompt Machine as a prompt pack.

Teach the worldview first:

```text
context
→ workflow
→ constraints
→ output
→ review
→ iteration
```

Seed problems such as:

- insufficient context;
- one giant prompt trying to be a whole process;
- no output contract;
- no review step;
- using AI to skip understanding;
- inability to reuse a workflow.

When the product arrives, the product should feel like the operationalized version of ideas the account already taught.

## 13. Measurement protocol

For every post, persist:

```text
date
role
topic
angle
hook_pattern
format
visual_pattern
CTA
views
watch/completion or slide-through
likes
comments
shares
saves
profile_views
followers_gained
```

Observation checkpoints when feasible:

```text
2h
24h
7d
```

Evaluate against role, not one universal KPI.

## 14. Decision policy

### Scale

Scale a pattern when repeated observations show it performs its intended job without causing obvious trust/quality degradation.

### Iterate

Iterate when signal exists but hook, visual or payoff underperforms.

### Kill / pause

Pause when:

- the same pattern repeatedly underperforms;
- it attracts the wrong audience;
- it produces vanity reach without profile/follower intent when intent is required;
- it creates excessive repetition;
- it weakens positioning.

## 15. Current baseline snapshot

As of 2026-09-11:

```text
followers       312

7d profile views 113
```

The account is in a strong relative growth window. The correct response is **not** to declare victory or freeze the current feed. The correct response is to preserve what works, increase hook/identity strength, diversify post jobs and improve measurement granularity.

## 17. Promotion boundary

This playbook may guide production now, but MK0 is not closed. No tactic here becomes a universal growth law until historical and future observations are normalized and reviewed.
