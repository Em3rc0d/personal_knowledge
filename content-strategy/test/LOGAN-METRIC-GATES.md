# Logan Metric & Editorial Gates

Status: `GENERATED / MK0 TEST CONTRACT`  
Updated: `2026-09-24`

These gates prevent growth pressure from turning into repetition, weak evidence or empty clickbait.

## GATE-01 — Provenance

Every important statement is one of:

- `OBSERVED`
- `INFERRED`
- `GENERATED`
- `OFFICIAL`
- `INSPIRED`

Pass: no inference is presented as platform fact.

## GATE-02 — New topic first

Every candidate must be checked against the historical topic ledger.

Pass only if:

```text
status = NEW
```

or there is an explicit documented exception:

- user-requested continuation;
- correction;
- genuinely new evidence;
- materially deeper treatment.

Fail:

- same topic with a different headline;
- same diagnosis with a different symptom wording;
- same myth rewritten;
- same post in another visual style.

## GATE-03 — Mechanism reuse != topic reuse

Pass:

> reuse a winning hook/retention mechanism on a different topic.

Fail:

> repost the winning topic because it performed well.

## GATE-04 — Role defined

Each post has one primary role:

```text
SEARCH
HERO
SHARE_ENGINE
LAB
```

and one primary success metric.

Pass: the post is evaluated against its intended job.

## GATE-05 — Hook integrity

Pass only if:

1. understandable quickly;
2. creates a real question/tension;
3. body resolves it;
4. technically defensible;
5. uncertainty remains visible when diagnosis is non-unique.

Automatic fail:

- fabricated danger;
- invented cost;
- certainty from an ambiguous symptom;
- generic shock wording unrelated to payoff;
- promised answer hidden behind comment bait.

## GATE-06 — Driver-first language

Pass:

> hook is expressed as a driver problem, decision, symptom or recognizable belief.

Fail by default:

> component lecture title with no user problem.

Exception: specialist/authority Lab experiment with explicit reason.

## GATE-07 — Retention structure

Carousel pass:

- each slide changes the information state;
- no filler slide;
- payoff is neither dumped instantly nor artificially delayed.

Video pass:

- first second communicates problem;
- no long intro/logo;
- motion/audio is useful to the idea.

## GATE-08 — Visual quality

Pass only if:

- 9:16 when intended for TikTok;
- phone-size readability;
- one dominant idea;
- no blur;
- no low-resolution source;
- no accidental white strip/band;
- visual clarifies or strengthens recognition;
- each carousel asset is separately usable;
- batch composition is not visually repetitive.

## GATE-09 — Search alignment

For `SEARCH` role:

Pass only if:

- one target query exists;
- cover/body/caption use the natural query language;
- no keyword stuffing;
- hashtags are semantically relevant;
- topic is new.

## GATE-10 — Comment mechanism

Given the current 0-comment seven-day snapshot, generic CTA is not accepted as a sufficient interaction strategy.

Pass if the post contains a genuine conversational decision, condition or disagreement.

Examples:

- A vs B diagnosis;
- “cold vs hot?”;
- “what would you verify first?”;
- competing workshop explanations.

Explicit CTA may be omitted.

## GATE-11 — Share mechanism

Pass if a viewer has an intrinsic reason to forward:

- prevent a mistake;
- verify before spending;
- recognize a common behavior;
- communicate a safety distinction;
- send a compact checklist.

“Share this” alone does not pass.

## GATE-12 — Product invisibility

Current public-content gate:

```text
product mention   FAIL
product teaser    FAIL
product branding  FAIL
product CTA       FAIL
```

This gate remains until intentionally changed.

## GATE-13 — Measurement windows

Record when available:

```text
T+2h
T+24h
T+72h
T+7d
```

Pass: unavailable values remain `UNKNOWN`.

No emotional deletion/reposting because T+2h is weak.

## GATE-14 — Current baseline context

Latest common recent distribution cluster:

```text
~475–600 views
```

Internal view bands:

```text
<300       weak signal
300–700    ordinary current range
700–1000   promising
1000+      candidate breakout
3000+      investigate mechanism deeply
5000+      high-priority replication attempt
```

These are operating bands, not platform rules.

## GATE-15 — SCALE

Scale only when the **mechanism** has evidence.

Candidate:

- clearly beats rolling baseline on distribution; and
- has at least one supporting downstream signal such as retention/completion, shares, comments, Search, profile action or follows.

Action:

> apply mechanism to a new topic.

One viral outlier does not establish a law.

## GATE-16 — HOLD

Hold when:

- ordinary views but useful Search/share/save/profile signal; or
- strong topic with mixed packaging.

Action:

> iterate mechanism on a new topic with one documented change.

## GATE-17 — KILL

Kill a mechanism after repeated failure across materially different new topics.

Do not kill a whole topic family because one execution failed.

Do not resurrect failed formats merely because ideation is difficult.

## GATE-18 — Cadence safety

Four posts/day allowed only while:

```text
NOVELTY             PASS
TECHNICAL_INTEGRITY PASS
VISUAL_QUALITY      PASS
MEASUREMENT         SUSTAINABLE
```

Otherwise reduce output.

## GATE-19 — Weekly falsification

Weekly review must answer:

- Which belief lost support?
- Which winner failed to repeat?
- Which role is generating actual audience growth?
- Is Search rising on intentionally aligned posts?
- Are shares increasing because content is useful or because one outlier dominates?
- Is four-post cadence causing fatigue?
- Did any topic accidentally repeat?

Pass: strategy can become less certain when evidence contradicts it.
