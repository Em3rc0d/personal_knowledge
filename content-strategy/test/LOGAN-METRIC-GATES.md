# Logan Metric & Editorial Gates

Status: `GENERATED / MK0 TEST CONTRACT`

These checks prevent narrative-driven decisions from replacing evidence.

## GATE-01 — Provenance

Every important claim must be classifiable as:

- `OBSERVED`
- `INFERRED`
- `GENERATED`
- `OFFICIAL`
- `INSPIRED`

Pass: no strategy inference is presented as raw platform fact.

## GATE-02 — Objective before metric

Each evaluated post should have a primary job when possible:

```text
reach
comments
saves
shares
profile visits
follows
search discovery
later conversion
```

Pass: a post is not judged only by views when it was designed for another job.

## GATE-03 — No-repeat

Before production, compare against recent content on:

```text
topic
symptom
diagnosis
hook mechanism
visual pattern
carousel structure
CTA
```

Pass: materially new, or explicitly labeled controlled variation / continuation / correction.

## GATE-04 — Hook integrity

Pass only if:

1. the hook creates real attention tension;
2. the body resolves it;
3. the claim is mechanically defensible;
4. uncertainty remains visible when diagnosis is non-unique.

Fail examples:

- catastrophic certainty from one ambiguous symptom;
- scanner-level promise with generic body copy;
- shock wording unrelated to the actual value.

## GATE-05 — Visual quality

Pass only if:

- first-frame hierarchy works at phone size;
- one dominant idea exists per slide;
- text is readable without zoom;
- imagery clarifies the mechanism or emotion;
- composition does not look unfinished or generic;
- requested carousel slides are individually usable.

## GATE-06 — Measurement completeness

At `T+2h`, `T+24h` and `T+7d`, record available metrics and leave unavailable values as `UNKNOWN`.

Pass: no invented follower/profile/conversion attribution.

## GATE-07 — Promotion

A mechanism may become a reusable pattern only after repeated evidence.

Current provisional candidate rule:

```text
GREEN candidate
= beats rolling median in >=2 objective-relevant metrics
```

One isolated winner is not enough for a universal claim.

## GATE-08 — Kill discipline

After three materially different attempts fail against the same intended objective, default action is archive.

Exception: continue only with documented new evidence, a materially different hypothesis or a strategic reason.

Pass: failed ideas do not return silently because topic generation became difficult.

## GATE-09 — Cadence safety

Four posts/day is allowed only while:

```text
visual_quality = PASS
novelty = PASS
technical_integrity = PASS
measurement = SUSTAINABLE
```

Otherwise cadence yields to quality.

## GATE-10 — Weekly falsification

Weekly review must ask at least:

- Which belief lost support?
- Which winner failed to repeat?
- Which format may look strong because of one topic?
- Which topic may look weak because of packaging?
- Did profile/follow conversion improve, or merely views?

Pass: the review contains at least one attempt to disconfirm the current strategy.

## GATE-11 — Profile isolation

Rules derived from Logan must remain profile-specific unless replicated elsewhere.

Pass: no Logan-specific hashtag, mix, hook or cadence rule silently overwrites Content Seller / LinkedIn / other channel rules.
