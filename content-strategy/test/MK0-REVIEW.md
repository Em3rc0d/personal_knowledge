## Logan consistency checks

- [x] 7-day metrics are marked `OBSERVED`.
- [x] Percentage deltas are not interpreted without considering baseline limitations.
- [x] Recent post views are not treated as controlled experiments when post age differs.
- [x] No causal ranking-algorithm claim is made from one analytics snapshot.

- [x] Profile-specific evidence is not automatically universalized.
- [x] Unproven items remain hypotheses for later MKs.
