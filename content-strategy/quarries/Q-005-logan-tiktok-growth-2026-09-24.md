## 5. What the recent batch suggests

`INFERRED / confidence: medium`

The stronger recurring editorial mechanism is broader than “technical diagnosis”.

It is:

```text
recognizable belief / habit / symptom
→ contradiction or uncertainty
→ short technical explanation
→ useful consequence
```

Examples of the mechanism that may work:

- “you think X means Y; not always”;
- “before paying for X, verify Y”;
- “this number / sound / habit does not mean what most people assume”;
- “two situations look similar but require different decisions”.

The mechanism may be reused. The **topic must not be reposted**.

## 9. Aggressive growth boundary

`GENERATED`

Aggressive means:

- stronger first-frame stakes;
- clearer user-centric language;
- faster comprehension;
- useful contradiction;
- money / risk / uncertainty framing when technically defensible;
- stronger visual stop power;
- deliberate experiments.

Aggressive does not mean:

- false danger;
- mechanical certainty from an ambiguous symptom;
- fabricated repair costs;
- unsupported claims;
- empty shock copy;
- withholding the promised answer to force engagement.

Rule:

```text
attention gained <= value actually delivered
```

### Curiosity / diagnosis

### Identity / disagreement

Use disagreement to create thought, not rage bait.

## 12. Retention design

`GENERATED / supported by first-party platform guidance on early attention and viewing behavior`

A carousel/video should not dump the answer in the first frame nor artificially delay it.

Preferred loop:

```text
HOOK
→ unresolved but honest question
→ useful clue
→ narrowed explanation
→ payoff
→ optional next-action / conversation trigger
```

Each slide/frame must earn the next one.

Cover rule:

```text
one dominant idea
4–9 words when practical
understandable in ~1 second
```

## 13. Search construction

For a Search post, define one target query before production.

Example structure:

```text
TARGET QUERY
“por qué mi carro X cuando Y”

COVER
“¿TU CARRO X CUANDO Y?”

BODY
repeat the natural symptom language, then explain

CAPTION OPEN
“Por qué un carro puede X cuando Y…”

HASHTAGS
few semantic automotive/topic tags; no dependency on #fyp
```

Avoid keyword stuffing.
